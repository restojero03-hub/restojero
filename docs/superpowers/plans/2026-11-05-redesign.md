# Redesign and Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the public site in the old site's look with freelancer-first copy, then add a logged-in dashboard that edits all of it.

**Architecture:** One validated content document (`lib/content/schema.ts`, defaults in `content/defaults.ts`) drives the page and the CV PDF. `getContent()` reads it from Neon when configured and falls back to defaults when not. Public pages stay static and regenerate on save.

**Tech Stack:** Next.js 16, Tailwind 4, shadcn/ui, zod, Prisma, Neon, Clerk, Vercel Blob, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-05-redesign-design.md`

## Global Constraints

- Work on branch `redesign/old-site-look`. Don't push or deploy until Ronil approves.
- No phone number anywhere. Email only in `site.cvEmail` and the PDF, never in page HTML.
- No third-party names or contact details. No invented facts.
- The site builds and runs with no environment variables set.
- A failed database read throws. It never publishes defaults over saved edits.
- Dark is the default theme. Both themes pass contrast checks.
- Test the full suite against a local build, and only spot-check live.

## Review Focus

- Dashboard security: every read and write of private data checks the admin, not just the page. A signed-in non-admin gets nothing.
- Bad content can't take the site down: invalid saves are rejected by the schema, and bad stored data doesn't crash the page silently.
- Uploads: only images, size limited, admin only.
- 320px phone: no sideways scroll, including the pop-up.
- Keyboard: pop-up, tabs, menu and Load more work without a mouse, and focus returns on close.
